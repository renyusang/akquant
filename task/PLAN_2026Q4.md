## 2. 核心问题（按重要性排序）

1. **转换率**：池子等权 8-14%/年，策略只有 -9%~+6%/年；策略平均只持有 **3.4-3.6/5** 个名额。
2. **参数与池耦合**：旧参数（entry 2%、downtrend 4%、trailing 4%、min_hold 0）都在后视池上得出。
3. **评估台架**：单路径、生存者偏差、无滑点、`pool_schedule` 无单测。
4. **A 股制度**：T+1/涨跌停/印花税/流动性/风格切换尚未完整建模。

## 3. 已确定的决策（新会话不要推翻，除非有新证据）

- 股票池：**40 只**、热门 ≤20%、主题 ≤30%、申万行业 ≤3、**季度**评审、粘性 + 换池时持仓并入。
- 参考窗口：季度口径用 **3M**；1M 仅在月度方案里考虑。
- 质量因子：**默认关**（`pool_rule.py --quality` 才开）。
- 实盘参数：**暂不改**；`min_hold` 不加入。
- 评估结论必须多起点 + 随机对照，单路径“最优”不作为采纳依据。

## 4. 计划

### P0：评估台架（1-2 周，先做）

- [ ] **滚动起点**：2022-04 / 2023-04 / 2024-04 各起一次，所有变体看 3 条路径分布。
- [ ] **随机对照**：每个池子规则配 5 个随机 40 只池，规则须落在 ≥75 分位。
- [ ] **滑点/冲击**：双边 10bp、20bp 敏感性；结论不得翻转。
- [ ] **生存者偏差**：纳入退市/ST（或量化偏差方向与上界）。
- [ ] **单测**：`pool_schedule` 切池、持仓并入、粘性评审各补 1-2 例。
- 验收：同一结论在 ≥2/3 起点同向、滑点后仍成立、测试全绿。

### P1：新池上的参数/开关重测（2-3 周，用户明确要求）

固定 rule40 / 季度 / 粘性 / 持仓并入 / 真实费率：

- [ ] 入场：`entry_threshold` 1.5/2/2.5/3%
- [ ] 逆势入场：`downtrend_entry_threshold` 3/4/5%
- [ ] 退出：`exit_threshold` 0.5/1/2%、`trailing_stop_pct` 3/4/5%
- [ ] 最小持仓：`min_hold_bars` 0/10/20（研究值，不默认采纳）
- [ ] 过滤：`mfi_filter_enabled`、`trend_confirm_bars`、`trend_recover_confirm_bars`
- [ ] 结构：`max_positions` 5/6/8、`single_position_pct` 0.12-0.20、`priority_mode`
- [ ] 语义：`peak_persist_enabled` 开/关
- **采纳门槛**：多起点同向 + 夏普 +0.1 以上 + 回撤不恶化 >3pp + 参数平台（非单调即排除）+ 无单年依赖。

### P2：转换率与仓位（P1 之后）

- [ ] 诊断“为什么只用 3.5/5 个名额”：信号频率、20% 上限、整手、建仓价。
- [ ] 对比 5 只×20% vs 6-8 只×12-15% vs 分批建仓。
- [ ] 目标：策略收益 ÷ 池等权收益 ≥50%。
- [ ] 单只可买性过滤：一手成本 ≤ 单只上限（股价 ≤600；科创板 ≤300 且 200 股/手）。

### P3：池子收敛（不再精调）

- [ ] 维持 40 只、热门 ≤20%、季度、3M；质量因子等覆盖率 >90% 再复评。
- [ ] 评审台账继续用 `pool_review.py` + `pool_kpi.py`，每月留痕。

### P4：纸面/小资金验证（3-6 个月）

- [ ] 新池 + 新参数纸面运行，按月对账胜率/换手/滑点；
- [ ] 通过门槛后再迁移实盘资金；在此之前 `stocks.yaml` 不动。

## 7. 风险与纪律

1. 4.5-5.5 年单路径，任何 5-10pp 差异都可能是噪声；先看分布再看均值。
2. 生存者偏差会让所有小盘/题材结论偏乐观；报告必须注明。
3. 等权池收益 ≠ 策略收益；不得用选择层数字承诺实盘。
4. 每次只改一个变量；参数平台优先于单点最优。
5. 实盘变更必须带备份（`stocks.yaml.bak_YYYYMMDD`）+ 测试 + 部署记录。
