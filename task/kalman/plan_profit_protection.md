## 0. 摘要(TL;DR)

1. **现象属实, 但比直觉更窄**。**可决策口径**下, 2,061 笔中 **464 笔(22.5%)** 曾出现 ≥+0.5% 浮盈
   而最终净亏, 中位回吐 4.63pp, 合计亏损 ¥-350,210 = **总净亏的 21.8%**。
   但按"浮盈幅度"分解: 亏损总额的 **78.2% 来自"买入后从未浮盈"的单子**(峰值 ≤+0.5%, 835 笔), 而不是"赚过又亏回去"。
   真正"浮盈 >4% 后亏掉"的只有 **111 笔 / 总净亏的 5.4%**。
   (口径必须写明: 日内极值口径为 51.8%, 收盘全窗口口径为 30.6% —— 见 §1.1。)
2. **在现行 -4% 峰值回撤之外再做"提前离场"式收紧, 数据不支持**。校准后的单笔重放(2,061 笔, 命中率 92.9%)显示:
   保本止损、随浮盈收紧的移动止盈、硬止损收紧、结构止损 —— **全部净负**, 且"早出场更优 : 更差 ≈ 1 : 10"
   (详见 §4)。与既有 4 项证伪同族(固定目标止盈 -66~-90pp、时间止盈中性、MA20 单年依赖、止损收紧 IS/OOS 冲突)。
   ⚠️ 与"是否保留既有保护机制"是两回事: 组合口径下**既有**移动止盈是正贡献(§3.3), 故 P0 的方向是**修好它**而不是取消或加码。
3. **但发现一个真实缺陷(优先级最高)**: 实盘的"峰值回撤止盈"**不是移动止盈**——
   `daily_signal.py` 每日重建 `SignalEngine`, 峰值被重置为持仓成本且预热过程不恢复它,
   于是该规则退化为 **"相对成本 -4% 的硬止损"**; 而回测里峰值是跨 bar 单调累积的**真·移动止盈**。
   **回测基线的浮盈保护机制, 在实盘不存在**(代码 + 实盘案例双向验证, 见 §3)。
   **量化**: 实盘等价语义的组合回测 = **1,180,489(+195.1%)**, 比记录的 1,332,424(+233.1%)少 **¥-151,935 / -38.0pp**
   (股票池 -57.9pp, ETF 池 +21.9pp)。项目文档里的 +233.1% 不是实盘系统的真实语义。
4. **因此本计划的形状**: 先修语义缺陷(P0, 预期 +¥95k~152k 量级), 再建观测层(P1, 含把"回吐"做成可追踪 KPI),
   再对**尚未被证伪**的少数候选(P2)按仓库门槛立项;
   并**明确接受**"买入后无跟随"的 78% 亏损主体——除非入场端找到新证据。

## 1. 现象的定义与量化(2020-01-02 ~ 2026-09-17, 生产基线 2,061 笔)

### 1.1 两个口径, 差别很大, 结论必须以可执行口径为准

| 口径 | 定义 | 曾浮盈 ≥0.5% | 曾浮盈且最终亏损 | 亏损单中曾浮盈占比 |
|---|---|---|---|---|
| ① 极值口径(akquant `mfe`, 日内 high) | 持仓期内价格曾触及 | 89.5% | 51.8%(1,068 笔) | 84.3% |
| ② 收盘全窗口(含入场/出场 bar 收盘) | 收盘价曾站上成本 +0.5% | 68.2% | 30.6%(631 笔) | 49.2% |
| **③ 可决策口径**(**结论口径**) | 仅在引擎**能看到持仓、且能在该收盘做决策**的区间取样 | 59.5% | **22.5%(464 笔)** | 36.2% |

> ⚠️ **口径差异本身就是结论之一**: 本系统在收盘算信号、次日开盘成交, 没有任何盘中动作路径
> (`orders.py:3-7`, `orders.py:172-184`: 所有买卖都是隔夜单)。
> 因此"盘中看到的浮盈"里近一半是**规则无法触及**的——它只能在收盘价上做判断。
> 口径③ 进一步剔除了两类**不可决策**的收盘: 成交当日(引擎在 `on_bar` 时还看不到持仓)与出场 bar
> (该 bar 的卖出已在开盘成交, 收盘价发生在成交之后)。**后续所有结论一律用口径 ③**;
> ②是③的上界(相差 8.1pp), ①仅作对照。复现: `python study_giveback.py --report`。

### 1.2 现象画像(口径 ③ 可决策)

- 464 笔"曾浮盈 ≥+0.5% 后净亏": 回吐合计 2,467pp, 中位回吐 **4.63pp**, 合计净亏 **¥-350,210**
  = 总净亏(¥-1,605,652)的 **21.8%**; 分池(曾浮盈且亏损的比例): 股票池 21.3% / ETF 池 24.6%。
- 按浮盈幅度分档递增收紧: ≥1% 387 笔 / ≥2% 257 笔 / ≥3% 181 笔 / ≥5% 71 笔 —— 各档都有, 回吐不是少数极端单造成的。
- (年度分布见基线: 亏损单占比 41%~56%, 无单年集中 → 属长期结构性特征, 非某年行情。)

### 1.3 关键分解: 亏损主体是"从未浮盈", 不是"浮盈回吐"

| 群体 | 笔数 | 占比 | 亏损单中位收益 | 净亏合计 | 占总净亏 |
|---|---|---|---|---|---|
| **从未浮盈**(口径③ 峰值 ≤+0.5%) | 835(其中亏损 **819**) | 40.5% | **-3.92%** | **¥-1,255,442** | **78.2%** |
| 浮盈 >0.5% 后亏损 | 464 | 22.5% | — | ¥-350,210 | 21.8% |
| └ 其中**浮盈 >4% 后亏损** | **111** | **5.4%** | -1.20%(峰值中位 +5.62%) | **¥-86,477** | **5.4%** |
| 全部亏损单 | 1,283 | 62.3% | — | ¥-1,605,652 | 100% |

> (两组按"是否曾浮盈"互斥切分: 819 + 464 = 1,283 笔亏损单。)

**读法**: "买入时盈利、卖出时亏损" 的字面版(赚过又亏回去)**只占亏损池的 5.4%**;
更多的情况是**买入后从未走出一段像样的浮盈**, 被 -4% 规则砍掉(中位 -3.92%)。
两类问题的处方完全不同: 前者是**退出结构**, 后者是**入场质量 / 止损距离**。

### 1.4 实盘侧证据(样本小, 仅作动机)

- 实盘全部卖出信号 2026-07-17 ~ 09-28 共 **69 条**: 价格回归 49 / 止损 17 / 峰值回撤止盈 2 / 速度反转 1。
- **2026-09-28 单日 6 笔卖出**(本次立项的直接触发): 5 笔"止损"(-6.3% ~ -8.8%) + 1 笔"峰值回撤止盈"(-4.8%);
  逐一核对持仓期最高收盘相对成本: **+0.2% / -1.1% / +0.1% / +0.5% / +3.4% / -0.2%** ——
  即这 6 笔**基本没有过像样的浮盈**, 属于 §1.3 的"从未浮盈"类(被 -4~-5% 规则止损), 不是"浮盈回吐"类。
  → 用户看到的"买入时盈利"更可能来自**盘中/日内的短暂上冲**(极值口径), 而非可执行的收盘浮盈。

## 2. 归因: 回吐发生在哪一步?(校准重放, 命中率 92.9%)

方法: 对 2,061 笔按"峰值与决策从成交次日起 / 收盘触发 / 次日开盘成交"重放规则, 并与实际出场 bar 对账。
**校准结果: 模型触发的 1,038 笔中, 964 笔(92.9%)与实际出场 bar 完全一致, 96.4% 在 ±1 bar 内** ——
口径已对齐, 可用于候选筛选(这是本计划所有单笔结论的前提)。
自校验: "现状 trail 4%" 单笔 Δ = **-6,175**(净收益的 -0.66%), 与 `kalman.md` 记录的 trail "收益 -0.7pp" **独立吻合** ✅

**出场归属**: 移动止盈触发 1,038 笔(50%), 其余 1,023 笔由价格回归/速度反转等规则出场。

**隔夜跳空不是回吐主因**(964 笔止盈归属出场的实测):

| 指标 | 决策收盘 → 次日开盘 |
|---|---|
| 跳空均值 / 中位 | -0.16pp / -0.03pp |
| 负跳空占比 | 51% |
| 跳空 < -3pp / < -5pp | 5% / 2% |

→ 跳空接近"公平硬币", 极端负跳空是尾部(如 300502: 决策收盘 +9.5% → 春节后开盘 -1.5%), 但**不是普遍机制**。

**真正的损耗结构**: 移动止盈触发者的**峰值浮盈中位仅 +3.0%**, 而最终收益中位 -2.60%。
即: 大多数单子峰值本来就薄, 规则要求"先回撤 4%"才动手, 等它触发时价格已经回到成本下方。
**这是"薄浮盈 + 4% 容忍带"的算术结果, 不是规则失效。**

## 3. ★ 真实缺陷: 实盘的峰值回撤止盈不是移动止盈

### 3.1 代码证据(四处, 可自行复核)

| 位置 | 内容 |
|---|---|
| `signal_engine.py:390` | `self._peak_price: float = 0.0` |
| `signal_engine.py:429-435` | `set_position()`: 开仓时 `_peak_price = entry_price` |
| `signal_engine.py:716-717` | 仅 `update()` 内: `if self._has_position and close > self._peak_price: self._peak_price = close` |
| `process_history`(`signal_engine.py:437-504`) | **只预热 `_kf` / `_trend` / ADX/RSI/BB/MFI 窗口, 从不触碰 `_peak_price`** |

- **实盘**(`daily_signal.py:241-245`): 每个标的**每天重建一个全新 `SignalEngine`** →
  `set_position(has_pos, avg_cost)` 把峰值设为**持仓成本** → 预热不恢复峰值 → 当天唯一一次 `update(close_T)`
  最多把峰值抬到 `close_T`。**∴ 峰值 = max(成本, 当日收盘)** → 规则 `(峰值-收盘)/峰值 ≥ 4%` 只在
  `close_T < 成本 × 0.96` 时成立 = **一条 -4% 的成本止损, 跨日不累积, 完全不保护浮盈**。
- **回测**(`strategy.py:375-377`): 引擎在整段回测中存活, 每 bar `set_position()` 但 `_has_position` 已为 True
  → 重置分支不触发 → 峰值跨 bar 单调累积 = **真·移动止盈**。

两者是**两个不同的机制**, 而 `kalman.md` 的退出端结论(以及 +233.1% 基线)全部来自回测口径。

### 3.2 实盘案例(两项, 均为成本被当成峰值)

| 案例 | 事实 |
|---|---|
| **300604 长川科技** | 09-21 以 286.09 建仓(单日持仓), 09-22 卖出信号 "峰值回撤止盈(**峰值286.09**回撤4.6%)" —— 峰值 = 成本, 无跨日累积 |
| **001270 铖昌科技** | 09-28 信号 "峰值回撤止盈(**峰值100.85**回撤4.8%)": 持仓成本 100.847, 而该持仓期内**最高收盘 100.22** —— 报出的峰值**高于持仓期任何一根收盘**, 只能来自成本 |

### 3.3 影响量化(实验 A/B + 官方扫描, 全区间 2020-01-01~2026-09-18)

同一份代码/数据/参数, 只切换峰值语义(脚本 `/tmp/live_semantics_probe.py`; OFF 行由 `sweep_params.py` 产出):

**读法**:
1. **A 行与 `kalman.md` 批次3 生产基线逐元吻合**(1,332,424 / 股票池 323.4%/1.59/-15.2%) → 台架可信。
2. **实盘语义(B)相对回测(A)少 ¥-151,935**(组合收益 -38.0pp; 股票池 -57.9pp / ETF 池 +21.9pp)。
   即: 项目记录里的 +233.1% **不是实盘系统的实际语义**, 实盘等价语义是 **+195.1%**。
3. **拆解**: `A - C = +¥94,724`(保护机制本身的价值) **−** `C - B = ¥57,211`(退化后的 -4% 成本止损比"什么都不做"更差, 即 B 比 C 又少 57,211)。
   即实盘同时吃了两份亏: ①没有浮盈保护 ②多了一条有害的更紧止损。合计 94,724 + 57,211 = **¥151,935 = A - B** ✓
4. **跨池不一致**: 保护机制在股票池 **+38.5pp**、在 ETF 池 **-20.9pp**(ETF 池自身为负期望池, 6.5 年 -16%~-38%)。
5. **与既有记录的关系(批次0.1 已定位, 见下)**: `kalman.md` 9-17"生产启用项复核"把 trailing 5% 的收益贡献记为 **-0.7pp**。
   本次用同一台架复现该行配置(**downtrend_entry 3% + trail 5%**, 临时 config `/tmp/stocks_dt3.yaml`)测得:
   `关=277.7% / 1.34 / -16.8%` vs `开=279.3% / 1.42 / -14.8%` → **+1.6pp / 夏普 +0.08 / 回撤 +2.0pp**。
   即**在该旧配置下该规则确实近似中性**(与 -0.7pp 同处噪声量级, 差异可归因于数据右端/口径)。
   **但该结论不可外推到当前生产配置**: 同一规则在 **dt4/trail5 = +11.0pp**、**dt4/trail4 = +38.5pp**。
   → **参数不可分离**: "收益贡献消失"只对 9-17 的 dt3/trail5 配置成立。
   **结论**: 旧行保留但必须加注"仅适用 dt3/trail5"; 引用时一律以本表(§3.3)为准, 不得再写"trailing 收益贡献消失"。

## 4. 单笔口径证据: 收紧退出普遍为负(校准后)

同一 2,061 笔, 决策从成交次日起(收盘触发)、次日开盘成交, **新规则只允许早于原出场**(资金再投效应未计)。

| 规则 | 触发 | 早出场更优 / 更差 | Δ金额 | 股票池 | ETF 池 |
|---|---|---|---|---|---|
| 现状 trail 4%(验证行) | 1,038 | 36 / 1,002 | **-6,175** | -7,169 | +994 |
| 保本止损 arm=1% +0.2% | 419 | 68 / 351 | **-22,756** | -16,653 | -6,103 |
| 保本止损 arm=2% +0.2% | 272 | 20 / 252 | -11,660 | -10,020 | -1,640 |
| 保本止损 arm=3% +0.2% | 184 | 7 / 177 | -7,854 | -7,587 | -267 |
| 收紧 trail: min(4%, max(2.5%, 0.25×峰值)) | 1,531 | 230 / 1,301 | -16,229 | -15,636 | -593 |
| 收紧 trail: min(4%, max(2%, 0.5×峰值)) | 1,603 | 251 / 1,352 | **-115,313** | -113,530 | -1,783 |
| 结构止损: min(峰值×0.96, 入场×0.98) | 566 | 28 / 538 | -3,077 | -4,071 | +994 |
| 硬止损 -2%(替代 -4%) | 948 | 147 / 801 | **-111,927** | -117,482 | **+5,555** |
| 硬止损 -3% | 680 | 68 / 612 | -27,452 | -30,113 | +2,661 |

**读法(三条)**:
1. **没有任何收紧版本为正**; 越紧越差(-2% 硬止损 -¥112k ≈ 净收益的 -12%)。
2. 优/劣比 ≈ **1:10** —— 动量策略在回撤后倾向反弹, 提前离场是系统性地砍右尾(胜率 37.7%, 收益靠右尾)。
3. **唯一一致的正面信号在 ETF 池**(硬止损 -2%: +5,555; 结构止损 +994), 股票池反向 ——
   与仓库已记录 4 次的"单池有效、组合无关"模式同型 → 按门槛**不予采纳**。

> **结论**: 本策略里"保护浮盈"≈**零和偏负**。这解释了为什么历史上 4 条同族路线全部折戟。
> 因此**不建议**把资源投入"更早离场"类机制。
>
> **⚠️ 但单笔口径 ≠ 组合口径(必须一起看)**: §3.3 的组合实验显示, **启用**移动止盈(峰值单调累积)相对**关闭**为
> 股票池 **+38.5pp / 夏普 +0.24 / 回撤 +4.5pp / 交易 1,313 vs 1,219**。
> 即"出场更早"在单笔上是负的, 在组合上是正的 —— 差额来自**锁盈后资金再投的循环**
> (更早释放的仓位买到下一次突破)。这正是 `kalman.md` 反复出现的"单笔特征在组合层难转化"的**镜像版本**,
> 也再次说明**组合口径才是决策口径**(§6-7)。本计划所有"收紧类"结论以单笔口径做**筛选**, 以组合回测做**裁决**。

## 9. 风险与反面论点(先写在前面)
