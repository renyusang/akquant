# 无限仓位信号发生器（unlimited_signal）

不限制资金和持股数量的信号发生器。与 `daily_signal.py` 相比**仅解除资金与持股数量限制**，其余（信号逻辑、T+1 次日开盘执行、涨跌停保护、备份/校验/快照、报告部署）完全一致。独立运行、独立状态文件，不干扰实盘系统。

---

## 一、仓位规则（核心差异）

**买入数量 = target_pct 映射到 [1, 3] 手（交易所最小单位）**

| 参数 | 值 | 说明 |
|---|---|---|
| 最小买入单位 | 交易所规定：主板/创业板 100 股，科创板 200 股 | 与实盘一致（688 → 200） |
| 最低买入数量 | 1 × 最小单位 | 下限 |
| 最高买入数量 | 3 × 最小单位 | 上限（例：深市 100→300 股） |
| 映射公式 | `qty = max(1, round(target_pct × 3)) × 最小单位` | target_pct 0.30→1手(100股)；0.95→3手(300股) |

**示例**（深市主板，最小 100 股）：

| 信号 | target_pct | 买入数量 |
|---|---|---|
| 下跌趋势买入 | 0.30 | 100 股（1 手） |
| 上涨趋势买入 | 0.95 | 300 股（3 手） |
| 趋势翻转补仓 | 0.30→0.95 | 补至 300 股（加 200 股） |

**卖出**：卖出信号 → 清仓该标的全部持仓（与实盘一致，无部分卖出）。
**加仓**：趋势翻转补仓保留（无资金限制后补仓 = 追加买入至目标手数）。

## 二、系统边界

| 维度 | 与实盘（daily_signal） | 与无限仓位（unlimited_signal） |
|---|---|---|
| 资金/持仓数 | 分池资金 200k/100k，最多 5 只，单只 20% | **无限制**（不限资金、不限只数） |
| 配置 | `stocks.yaml` | **独立** `unlimited.yaml`（同构，后续可改） |
| 状态文件 | `positions.json` 等（kalman 目录） | **独立**（`task/select/unlimited/` 目录） |
| 信号逻辑 | SignalEngine（卡尔曼+趋势过滤+过滤器） | **同一套 SignalEngine**（复用） |
| 执行 | T+1 开盘价 + 涨跌停保护 | 相同 |
| 备份/校验/快照 | 有 | 相同 |
| 报告 | live_report.html → 服务器 /live/ | 独立报告 → 服务器 /unlimited/ |

**注意**：持仓上限检查（max_positions/资金不足）逻辑在无限仓位版中**移除**，仅保留涨跌停保护；`_target_pct` 保留逻辑继续用于补仓。

## 三、报告增强（相对实盘报告）

### 1. 股票搜索框
页面顶部搜索框，输入股票代码（或名称）→ 高亮/过滤显示该股票：
- 信号历史（signals 表内该股行）
- 当前仓位（持仓表中该股）
- 交易情况（交易明细中该股买卖记录）
- 实现：纯前端 JS 过滤（输入 → 遍历表格行显示匹配），无需后端

### 2. 归一化收益
**定义**（每只股票独立核算）：
```
总资金   = 3 × 最小买入单位 × 买入价（首次买入成交价）
总利润   = 已实现盈亏（卖出记录）+ 浮动盈亏（当前持仓市值-成本）
归一化收益 = 总利润 / 总资金
```
- 每只股票视为"以 3 手为满仓"的独立小组合
- 已清仓股票：总资金 = 3×单位×首笔买入价；总利润 = 累计已实现
- 在持仓/交易汇总中新增列：归一化收益

### 3. 归一化收益排序 + 图表
- 全部标的按归一化收益降序排列（表格 + 柱状图，绿盈红亏）
- 图表与实盘报告同款 Plotly

    └── test_unlimited.py   # 仓位规则/执行/归一化收益单测

## 五、待确认/可调项

1. **买入数量映射**：`round(target_pct × 3)` 四舍五入——下跌 0.30→0.9→1 手，上涨 0.95→2.85→3 手 ✓；若希望下跌严格 1 手、上涨严格 3 手（无视中间值），改用 `1 if trend=down else 3`，待定
2. **归一化收益的"买入价"**：首次买入成交价（而非信号价）——默认成交价
3. **ETF 是否纳入**：与 stocks.yaml 一致（股票+ETF 都支持，ETF 最小单位 100）
4. **回测支持**：本期只做实盘信号；回测可后续基于 portfolio_backtest.py 改造仓位逻辑
