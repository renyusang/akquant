# 科学选股工具链

用**策略自身的回测结果**筛选"适配卡尔曼策略"的股票，替代人工拍脑袋选 watchlist。
核心方法：**双窗口样本外验证**——筛选期（2020-2024）盈利且验证期（2025-2026）也盈利的股票才推荐，
防过拟合（对齐项目击穿幸存者偏差的研究纪律）。

工具链三个脚本 + 一个数据文件：

| 脚本 | 作用 | 数据源 |
| :--- | :--- | :--- |
| `pool_provider.py` | 候选池生成（指数成分 + 过滤） | **akshare 免费源**（默认） |
| `screen_pool.py` | 双窗口回测 + 推荐过滤 + 分级过滤 | 本地 .catalog + risk_flags.csv |
| `diversify_recommend.py` | 行业分散（cap）+ TOP N 输出 | industry_cache.csv |
| `industry_cache.csv` | 推荐标的行业映射 | 妙想查询 + 人工分级 |

**数据源策略**：akshare 免费源覆盖选股主流程（指数成分/行情/ST），妙想 MCP 保留给
两个高价值低频场景——**风险分级**（公司违规事件，akshare 无接口）和**行业批量查询**。

---

## 一、方法论

| 环节 | 说明 |
| :--- | :--- |
| 候选池生成 | 四指数成分（HS300/中证500/创业板50/科创50）+ 动量池，市值>100亿/成交额>1亿/非ST 过滤 |
| 红线前置剔除 | 财务造假/重大行政处罚/立案/退市风险 → 回测前剔除（省算力、防污染推荐） |
| 双窗口回测 | 筛选期 in(2020-2024) + 验证期 out(2025-2026)，策略参数与实盘一致 |
| 推荐过滤 | 双窗口盈利 + 交易频率适中 + 回撤可控（阈值见下） |
| 行业分散 | 单行业 cap 3 只（避免 AI 算力主线同涨同跌风险） |
| 黄线标注 | 会计差错/近期监管函等 → 推荐时标注 ⚠️，人工决定是否保留 |

**分级过滤的必要性**（2026-08-13 实证）：28 只妙想候选**全部**带"违规"标记
（警示函/问询函/短线交易等轻重不一）——若全前置过滤会误杀所有候选。
因此分级：red 前置剔除、yellow 后置标注、light 忽略。

## 二、候选池生成（pool_provider.py）

akshare 免费源，指数成分接口实测：沪深300/中证500/科创50（csindex）✅、
创业板50（新浪兜底）✅、全市场行情（东财，限流时新浪回退）✅、ST 列表 ✅。

```bash
# 四个核心指数生成候选池
python pool_provider.py --output candidates_ak.csv

# 自定义指数/过滤条件
python pool_provider.py --indexes 000300,000905,399673,000688 \
    --min-market-cap 100 --min-turnover 1 --output candidates_ak.csv

# 合并妙想导出的 CSV（动量池等）
python pool_provider.py --miaoxiang-file candidates_full.csv \
    --output candidates_ak.csv
```

**数据一致性验证**（2026-08-14）：akshare 756 只 ⊆ 妙想版 828 只（指数成分完全一致，
差异仅过滤条件）——双源可无缝切换，妙想不可用时选股流程不中断。

**踩坑记录**（均有测试覆盖）：
1. 新浪代码带 `sh/sz` 前缀 → 统一 6 位纯数字（否则全市场匹配失败）
2. csindex 列选择必须优先"成分券代码"——"指数代码"列全是指数自身（000300）

## 三、双窗口筛选（screen_pool.py）

```bash
python screen_pool.py --symbols-file candidates_ak.csv --risk-file risk_flags.csv
```

### 风险分级（risk_flags.csv）

```
code,severity,note
000636,red,2019年财务造假(应收账款操纵被行政处罚)
300489,yellow,2021年报净利润会计差错更正(监管措施)
301165,light,2023年高管配偶短线交易警示函(个人行为)
```

| severity | 级别 | 处理 |
| :--- | :--- | :--- |
| `red` | 红线：财务造假/重大行政处罚/立案/退市风险 | **前置剔除**（数据下载/回测前） |
| `yellow` | 黄线：会计差错/1年内监管函/重大事项未披露 | 推荐时标注 ⚠️ 供人工判断 |
| `light` | 轻线：历史问询/高管个人行为 | 忽略 |

分级流程：妙想查公司事件 → AI/人工判定严重性 → 写入 CSV（判定标准见上表）。

### 输出列（16 列）

`symbol/name` + `in_ret/in_sharpe/in_mdd/in_ntrades/in_winrate`（筛选期 5 指标）
+ `out_*`（验证期 5 指标）+ `in_watchlist/recommended/pre_filtered/risk_note`

### 推荐过滤阈值

| 条件 | 阈值 | 依据 |
| :--- | :--- | :--- |
| 双窗口盈利 | in_ret > 0 且 out_ret > 0 | 样本外稳健 |
| 交易频率 | 筛选期 30~300 笔，验证期 ≥15 笔 | 全池实证：低频交易股大幅恶化(-32.5pp) |
| 回撤 | out_mdd < 40% | 控制尾部风险 |

## 四、行业分散（diversify_recommend.py）

推荐可能行业扎堆（2026 年 AI 算力主线：光模块/PCB/半导体），需分散风控。

```bash
python diversify_recommend.py --input screen_pool_full_result.csv \
    --cap 3 --top-n 20 --output recommended_watchlist.csv
```

- 行业字段来源：`industry_cache.csv`（妙想批量查询 + 本地缓存，避免重复调用）
- akshare 行业接口（`stock_individual_info_em`）东财限流时不可用 → 妙想兜底
- 单行业 cap 后按验证期收益取 TOP N
