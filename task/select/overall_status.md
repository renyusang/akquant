# 四象限框架与“主信号/过滤器/风控”三层结构

## 一、框架来源与核心目标

该框架出自 **AKQuant 官方教学文档**《[按策略场景选指标速查表（四象限）](https://akquant.akfamily.xyz/guide/indicator_scenario_quickref/)》（仓库对应 `docs/zh/guide/indicator_scenario_quickref.md`），配套文档《[Rust 指标全量说明](docs/zh/guide/rust_indicator_reference.md)》、《[指标组合实战手册](docs/zh/guide/talib_indicator_playbook.md)》、《[第16章 指标全景与工程化使用](docs/zh/textbook/16_rust_indicators.md)》。

> **核心目标**：先选场景、再选指标，减少选指标时间，优先保证策略结构完整（主信号 + 过滤器 + 风控）。

即：**不要单指标独立使用**，而是按场景进入象限 → 按三层结构组合指标。

---

## 二、四象限框架（按策略场景选指标）

| 象限 | 核心任务 | 优先指标组 | 典型输出 |
| :--- | :--- | :--- | :--- |
| **趋势** | 找方向、确认趋势持续性 | `EMA/SMA/TEMA/KAMA/SAR` + `ADX/ADXR` | 单序列为主 |
| **震荡** | 找超买超卖与回归机会 | `BBANDS/RSI/CMO/WILLR/STOCH` | 单序列 + 多输出 |
| **风控** | 控制波动风险与止损宽度 | `ATR/NATR/TRANGE/STDDEV/VAR` | 单序列 |
| **量价确认** | 减少假突破与信号噪声 | `OBV/MFI/AD/ADOSC/BOP` | 单序列 |

### 1) 趋势象限

- **适用市场**：单边上涨/下跌阶段；中高时间框架趋势延续行情
- **推荐组合**：
  - 基础：`EMA(20/60) + ADX(14)`
  - 增强：`EMA + SAR + NATR`
  - 平滑替代：`KAMA/T3` 替代固定参数均线
- **最小决策骨架**：

```python
trend_up = ema_fast[-1] > ema_slow[-1]
trend_strong = adx[-1] >= 20
enter_long = trend_up and trend_strong
```

### 2) 震荡象限

- **适用市场**：横盘箱体或波段往复行情；强趋势衰减后的回归段
- **推荐组合**：
  - 基础：`BBANDS + RSI`
  - 增强：`BBANDS + RSI + MOM`
  - K 线位置型：`STOCH/WILLR` 辅助入场确认
- **最小决策骨架**：

```python
oversold = close[-1] < lower[-1] and rsi[-1] < 30
momentum_ok = mom[-1] > 0
enter_long = oversold and momentum_ok
```

### 3) 风控象限

- **适用市场**：所有场景都应启用；尤其高波动、事件驱动阶段
- **推荐组合**：
  - 波动宽度：`ATR/NATR`
  - 动态止损：`SAR + ATR`
  - 波动过滤：`NATR` 阈值过滤开仓
- **最小决策骨架**：

```python
volatility_ok = natr[-1] < 4.5
trailing_stop = sar[-1]
risk_width = 2.0 * atr[-1]
```

### 4) 量价确认象限

- **适用市场**：突破策略、追涨策略、趋势确认策略；需要判断“价格动作是否有成交量支持”
- **推荐组合**：
  - 趋势确认：`OBV + AD`
  - 资金动量：`MFI + ROC`
  - 短线过滤：`ADOSC/BOP` 作为次级过滤器
- **最小决策骨架**：

```python
price_breakout = close[-1] > resistance
volume_confirm = obv[-1] > obv[-2] and mfi[-1] > 50
enter_long = price_breakout and volume_confirm
```

### 场景 → 指标快速映射

| 你要解决的问题 | 先看哪些指标 |
| :--- | :--- |
| 不知道当前是否有趋势 | `EMA + ADX` |
| 横盘中反复止损 | `BBANDS + RSI`，并增加 `ADX` 过滤 |
| 信号太多、胜率低 | 增加 `NATR` 与 `OBV/MFI` 过滤 |
| 止损不稳定、回撤大 | `SAR + ATR` 做动态止损 |
| 迁移后结果与老策略差异大 | 先 `backend="python"` 对齐，再切高性能后端 |

## 三、“主信号 / 过滤器 / 风控”三层结构

### 每层职责

| 层 | 回答的问题 | 典型指标 | 说明 |
| :--- | :--- | :--- | :--- |
| **主信号** | 何时、往哪个方向交易？ | `EMA/BBANDS/SAR` 之一 | 决定方向与入场触发，是策略的方向盘 |
| **过滤器** | 这个信号值得执行吗？ | `ADX/RSI/MOM` 之一 | 过滤低质量信号、减少假突破，提高胜率 |
| **风控** | 错了怎么办？ | `ATR/NATR` | 止损宽度、仓位控制、波动过滤，所有场景必启用 |

指标在策略中承担的角色还有第四种 **确认**（第 16 章归纳为：主信号、过滤器、风控、确认四类角色）。

### 调参顺序（避免参数空间爆炸）

官方推荐的固定顺序：

1. **先定交易风格**：趋势 or 均值回归（即先选象限）
2. **再定主信号**：`EMA/BBANDS/SAR` 之一
3. **再定过滤器**：`ADX/RSI/MOM` 之一
4. **最后定风险参数**：`ATR/NATR` 阈值与止损系数

### 四套组合模板

| 目标 | 推荐组合 | 触发逻辑骨架 |
| :--- | :--- | :--- |
| 趋势跟随 | `EMA + ADX + NATR` | 趋势方向 + 趋势强度 + 波动过滤 |
| 均值回归 | `BBANDS + RSI + MOM` | 偏离带宽 + 超买超卖 + 短动量确认 |
| 量价确认 | `OBV + MFI + ROC` | 价格方向先行，成交量信号放行 |
| 跟踪止损 | `SAR + ATR` | 趋势持有 + 动态止损宽度 |

```python
# 均值回归组合完整示例
upper, middle, lower = ta.BBANDS(close, timeperiod=20, backend="rust")
rsi = ta.RSI(close, timeperiod=14, backend="rust")
mom = ta.MOM(close, period=10, backend="rust")

long_signal = close[-1] < lower[-1] and rsi[-1] < 30 and mom[-1] > 0
exit_signal = close[-1] > middle[-1]
```

## 四、如何判断股票处于趋势还是震荡状态

判断"趋势 vs 震荡"（市场状态识别）有两条主线：**方向性**（价格是否持续朝一个方向运动）和**波动结构**（运动是单边还是往复）。工程上常用以下五类方法（按实用度排序）。

### 1) ADX 阈值法（最经典、首选）

ADX 衡量趋势**强度**而非方向——正是四象限文档里 `trend_strong = adx[-1] >= 20` 的用途：

```python
from akquant import talib as ta

adx = ta.ADX(high, low, close, timeperiod=14, backend="rust")

if adx[-1] >= 25:      state = "趋势"
elif adx[-1] < 20:     state = "震荡"
else:                  state = "过渡区(未定)"
```

判定标准：**ADX > 25 趋势、< 20 震荡**。注意 ADX 只告诉"有没有趋势"，不告诉方向——方向要看 `+DI/-DI` 或均线。

### 2) 均线排列 + 发散/缠绕

趋势的特征是均线**发散排列**，震荡的特征是均线**缠绕粘合**：

```python
ema_fast = ta.EMA(close, timeperiod=20, backend="rust")
ema_slow = ta.EMA(close, timeperiod=60, backend="rust")

spread = (ema_fast - ema_slow) / ema_slow          # 归一化间距
aligned = ema_fast[-1] > ema_slow[-1]               # 方向
trending = abs(spread[-1]) > 0.03 and spread[-1] * spread[-10] > 0  # 间距足够大且持续同向扩大
```

### 3) 布林带带宽法（挤压→突破信号）

带宽收窄 = 波动收缩 = 震荡蓄势（挤压 squeeze），带宽扩张 = 趋势启动：

```python
upper, middle, lower = ta.BBANDS(close, timeperiod=20, nbdevup=2, nbdevdn=2, backend="rust")
bandwidth = (upper - lower) / middle               # 归一化带宽

# 带宽低于历史 20% 分位 → 挤压状态,突破即将来临
squeeze = bandwidth[-1] < np.percentile(bandwidth[np.isfinite(bandwidth)], 20)
```

### 4) 效率比法（Kaufman ER，计算轻、响应快）

净位移 / 总路径长度。趋势中价格"直走"（ER→1），震荡中"来回走"（ER→0）：

```python
n = 10
net_move = abs(close[-1] - close[-n-1])
total_move = np.sum(np.abs(np.diff(close[-n-1:])))
er = net_move / total_move if total_move > 0 else 0
# ER > 0.5 → 趋势; ER < 0.3 → 震荡
```

### 5) 状态机交叉法（方向 × 波动率四态）

单指标可能误判（如高波动震荡期 ADX 也会升高），用两个维度交叉成四态更稳：

| 维度 | 趋势方向（EMA20>EMA60 或 +DI>-DI） | 强度/波动（ADX、NATR） | 状态 |
|---|---|---|---|
| 方向明确 + 强度高 | ↑ | ADX≥20 | **趋势**（顺势操作） |
| 方向明确 + 强度低 | ↑ | ADX<20 | 弱趋势（轻仓/观望） |
| 方向不明 | 缠绕 | — | **震荡**（均值回归/等待突破） |

### 6) 推荐落地组合（对齐四象限框架）

```
主信号(方向):   EMA(20) vs EMA(60)   → 多头/空头
过滤器(状态):   ADX(14) ≥ 20         → 是否趋势行情
风控(波动):     NATR 阈值             → 高波动时收紧/不开仓
```

对应四象限文档的"趋势跟随骨架"：`enter_long = trend_up and trend_strong`。

### 7) ADX 实战验证（2020-2026，5 标的 × 1589 交易日）

**ADX 数学原理**（14 日 Wilder 平滑）：`+DM/-DM`（定向位移）→ `+DI/-DI = 100 × SMA14(DM) / SMA14(TR)` → `DX = 100×|+DI - -DI| / (+DI + -DI)` → `ADX = SMA14(DX)`。本质：**上涨力度与下跌力度谁占主导、且主导多久**，不含方向信息。

**发现一：趋势/震荡是时变状态，不是股票属性**

| 标的 | ADX≥25 占比 | ADX<20 占比 |
|---|---|---|
| 平安银行 | 38% | 43% |
| 比亚迪 | 41% | 42% |
| 贵州茅台 | 37% | 42% |
| 上证50ETF | 33% | 46% |

5 只标的分布几乎相同——**任何股票都约 40% 时间处于趋势**。"这只股票是趋势股还是震荡股"是伪命题，正确问法是"当前处于什么状态"。

**发现二：ADX≥25 的趋势段确实对应单向行情，但有噪音**

比亚迪 2020-2026 共 12 个 ≥20 日的趋势段，多数方向明确（+44.5% 的 145 日段、+36.7% 的 41 日段、-11.4% 的 42 日段），但 4 个段收益不足 ±7%——ADX 高只说明"波动有方向性"，不保证方向持续。

**发现三：单指标有 19% 误判率——需交叉验证**

```
ADX≥25 且 ER≥0.5 (双确认趋势):  12%  ← 与效率比一致率仅 59%
ADX≥25 但 ER<0.3 (高波动震荡):  19%  ← ADX 虚高区
ADX<20 且 ER<0.3 (双确认震荡):  24%
```

**发现四：方向必须靠 +DI/-DI**

比亚迪 2026-06 实例：`ADX=29, +DI=10, -DI=41` → 强**空头**趋势。只看 ADX=29 会误以为可做多，实际是急跌段。

**正确用法**（判定流程）：

```python
from akquant import talib as ta
adx    = ta.ADX(h, l, c, timeperiod=14, backend="rust")
plus_di  = ta.PLUS_DI(h, l, c, timeperiod=14, backend="rust")
minus_di = ta.MINUS_DI(h, l, c, timeperiod=14, backend="rust")

state = "震荡" if adx[-1] < 20 else "趋势" if adx[-1] >= 25 else "过渡"
direction = "多头" if plus_di[-1] > minus_di[-1] else "空头"
# 组合: 趋势+多头 → 顺势开多; 趋势+空头 → 回避/开空; 震荡 → 不追涨杀跌
```

**陷阱清单**（均有数据佐证）：
1. ADX 不含方向——必须配合 +DI/-DI 或均线
2. 高波动震荡期 ADX 虚高（19% 时间）——用 ER 或 NATR 交叉确认
3. 滞后性：14 日双平滑，状态切换晚于行情拐点
4. 阈值 25/20 非普适：ETF（33%）比个股趋势时间更少，高波动品种应上调阈值
5. ADX 高位拐头向下 = 趋势衰竭，常先于价格拐头

### 8) ADX 门控接入与回测比较（2026-08-02 实测）

**接入方式**：`TrendDetector` 增加 ADX 门控——ADX < 阈值时视为震荡期，**锁定当前趋势方向**（不允许翻转，确认计数清零）；ADX ≥ 阈值时恢复原逻辑。参数 `adx_filter_enabled / adx_filter_threshold / adx_filter_period`（strategy.py 命名，SignalEngine 兼容 `adx_enabled` 等 yaml 别名）。三消费者（strategy.py 回测 / daily_signal.py 实盘 / portfolio_backtest.py）经 signal_engine 一处生效；main.py 新增 `--adx-filter / --adx-threshold / --adx-period`。`compute_adx` 纯 numpy 实现，与 akquant.talib ADX 逐点一致（max|diff|=0）。

**回测结果**（2020-01 ~ 2026-07，初始 10 万，T+1 开盘价成交，同参数仅 ADX 开关差异）：

| 标的 | 基线收益 | ADX≥20 收益 | 差值 | 夏普 基线→ADX | 交易 基线→ADX |
|---|---|---|---|---|---|
| 比亚迪 002594 | +24.8% | +20.6% | -4.2pp | 0.28→0.26 | 113→109 |
| 贵州茅台 600519 | +0.0%* | +17.3% | +17.3pp | 0→0.89 | 0→1 |
| 平安银行 000001 | +11.6% | +29.7% | **+18.1pp** | 0.21→0.46 | 78→75 |
| 深科技 000021 | -15.9% | +35.0% | **+50.9pp** | -0.29→0.42 | 43→41 |
| 长江电力 600900 | -1.7% | -1.7% | 0 | -0.02→-0.02 | 24→33 |
| 美的集团 000333 | -6.3% | +39.2% | **+45.6pp** | -0.06→0.53 | 62→81 |
| 宁德时代 300750 | -13.0% | -19.6% | -6.6pp | -0.04→-0.13 | 89→96 |

\* 茅台基线 0 交易为策略特性（波动小、2% 偏离阈值很少触发，非 bug）

**结论**：
1. **ADX≥20 门控 4/7 大幅改善、1 持平、2 略降**；收益中位数改善 +17.3pp，夏普 5/7 改善，回撤大多改善
2. **改善集中在"多数时间震荡、偶发趋势"的标的**（深科技/美的/平安）——门控锁定了震荡期 MA20 方向抖动，避免假趋势的来回交易
3. **代价**：大单边趋势标的（比亚迪/宁德）略损——ADX 滞后性延迟方向确认，趋势启动初期被当震荡锁定
4. **阈值 20 优于 25**：25 过度锁定（深科技 +35%→-14.7%），把弱趋势也当震荡
5. ⚠️ **7 只样本结论有幸存者偏差，已被全池验证推翻/修正**（见下节）

### 9) HS300 全池验证（2026-08-02，288 只有效标的，900 次回测）

脚本 `task/select/validate_adx.py`（multiprocessing 并行，结果 `task/select/adx_validation.csv`）。

| 指标 | 基线 | ADX≥20 | ADX≥25 |
|---|---|---|---|
| 收益均值 | +24.7% | +26.3% | +17.1% |
| 收益中位数 | -4.8% | -4.7% | -7.8% |
| 盈利占比 | 44.8% | 46.9% | 43.4% |
| 夏普中位数 | -0.017 | +0.011 | -0.063 |
| 回撤中位数 | 27.4% | 27.5% | 26.8% |
| 交易中位数 | 59 | 63 | 59 |

**配对比较**：ADX≥20 优于基线 129 只 / 劣于 158 只（胜率 45%，接近随机）；收益差均值 +1.57pp / 中位数 **-0.86pp**。ADX≥25 更差（均值 -7.57pp）。

**核心发现：ADX 门控效果与股票基线特征强相关**（改善幅度与基线收益相关性 **-0.58**）：

| 基线收益桶 | 数量 | ADX20 改善均值 | 优于基线占比 |
|---|---|---|---|
| <-30% | 8 | +28.6pp | 50% |
| -30~0%（亏损股） | 150 | **+14.0pp** | 56% |
| 0~30%（温和盈利） | 55 | -3.1pp | 36% |
| 30~100%（强势股） | 51 | **-12.7pp** | 35% |
| >100%（大牛股） | 23 | -31.4pp(中位) | 13% |

**结论**：
1. **全池层面 ADX 门控无系统增益**（胜率 45%、中位数微负、差异不显著）——此前 7 只样本的"4/7 大幅改善"是挑选标的带来的**幸存者偏差**
2. **效果高度分化**：基线弱势/亏损股（-30~0%）56% 改善（均值 +14pp）；强势/大牛股 65-87% 恶化（均值 -13pp 起）——机制是 ADX 锁定对震荡股减少假信号、对趋势股延迟确认，两者抵消
3. **低频交易股（基线 ≤30 笔）大幅恶化**（-32.5pp）：ADX 锁定期更少交易，错过仅有的趋势
4. **ADX≥25 系统性有害**（均值 -7.6pp）——过严锁定的负效应在全池确认
5. **可操作建议**：不作为全局开关；若要用，只对"基线回测亏损的股票"启用（自适应方案：先快速回测基线，负收益则启用 ADX 门控）

### 10) 震荡期识别与防高频买卖研究（2026-08-03 全池实证）

**研究问题**：如何更好地识别震荡期、避免震荡期高频买卖。

**实证 1：信号质量 vs 震荡指标（21811 个买入信号, 全池）**
买入信号后 20 根收益按 ADX/ER/布林带宽/EMA间距/NATR 分桶——**所有桶亏损率 47-52%、均值 +0.7~2.3%，无任何系统性差异**。震荡期买入信号并不比其他时期差，"识别震荡期"路线无效。

**实证 2：交易对视角（21690 个完整交易对）**
- **48.7% 的交易 5 根内快速反转**（持仓中位数仅 6 根）
- 快速反转：往返均值 **-3.07%**、亏损率 **81.7%**；正常持仓：+4.82%、34.1%
- **快速反转贡献了总亏损的 74.9%**
- 机制：`exit_threshold=0.5%` 过紧——买入后小幅回撤即被洗出，价格回升再买回，循环磨损

**实证 3：三种防磨损机制全池回测（288 只 × 5 配置, 4320 次回测）**

| 配置 | 收益均值 | 收益中位 | 夏普中位 | 优于基线 | 收益差中位 |
|---|---|---|---|---|---|
| 基线 | +24.7% | -4.8% | -0.017 | — | — |
| ADX≥20 门控 | +26.3% | -4.7% | +0.011 | 129/288 | -0.86pp |
| min_hold=10 | +22.3% | **-3.4%** | **+0.022** | 140/288 | **+0.00pp** |
| exit=1.5% | +22.2% | -6.2% | +0.018 | 141/288 | -0.39pp |
| exit=2.0% | **+39.5%** | -6.1% | +0.011 | 139/288 | -0.52pp |

**最终结论**：
1. **震荡期识别指标（ADX/ER/带宽/NATR）对信号质量无区分力**——"识别震荡期"路线证伪
2. **三种防高频买卖机制全池均无系统性增益**（中位数改善均在 ±0.5pp 内）——抑制坏交易的同时也消除了好交易/锁死了该止损的交易
3. **一致性分化规律**（所有机制相同）：基线亏损/震荡股受益（均值 +15~23pp）、基线强势/趋势股受损（-12~26pp）——磨损交易在震荡股是洗盘噪音、在趋势股是及时止损
4. **exit2.0 的 +39.5% 均值收益为右尾效应**（少数超级牛股大幅受益, 中位数反而 -6.1%）
5. **实操建议**：三种机制都不宜全局启用；若必须选一，`min_hold_bars=10`（中位数收益/夏普最优、收益差中位唯一非负）。"基线亏损股票才启用"的条件式方案理论上有效但需两阶段回测,样本外稳健性存疑
6. **根本问题在策略退出机制**（0.5% 回归阈值对震荡市过敏感），比加门控更值得探索的是**按波动自适应退出宽度**（如 ATR 缩放 exit_threshold）

**已实现代码**（默认关闭, 不影响现有行为）：
- `adx_filter_enabled / adx_filter_threshold / adx_filter_period`（TrendDetector ADX 门控）
- `min_hold_bars`（最小持仓周期, 止损优先）
- CLI：`--adx-filter --min-hold`；测试 116 全绿

### 11) 震荡反复买卖影响量化 + BBANDS+RSI 过滤器（2026-08-03 全池实证）

**震荡反复买卖的影响有多大**：
1. **结构影响**（实证 21690 交易对）：48.7% 交易 ≤5 根快速反转，亏损率 81.7%、往返 -3.07%，**贡献 74.9% 总亏损**
2. **摩擦成本**（10 只样例零摩擦回测）：平均每笔 0.06-0.10pp，全池中位数 59 笔 ≈ **3.5-6pp 收益被手续费吃掉**（占比小，主要影响来自快速反转本身的负收益）

**BBANDS+RSI 过滤器**（signal_engine.py 新增，纯 numpy，与 talib 逐点一致）：
- `rsi_filter_enabled / rsi_overbought`：RSI 超买（默认 >70）抑制买入（追高保护）
- `bbands_squeeze_enabled / bb_squeeze_ratio`：带宽 < 历史均值 × 0.5 抑制买入（挤压蓄势期不买；用历史窗口排除当前根，避免跳涨当天带宽瞬时扩大）

**全池回测（288 只 × 5 配置，1440 次）**：

| 配置 | 收益均值 | 收益中位 | 夏普中位 | 优于基线 | 收益差均值 | 回撤中位 | 交易中位 |
|---|---|---|---|---|---|---|---|
| 基线 | +24.7% | -4.8% | -0.017 | — | — | 27.4% | 59 |
| min_hold=10 | +22.3% | -3.4% | +0.022 | 140 | -2.35pp | 28.1% | 58 |
| RSI>70 过滤 | +20.8% | -2.9% | +0.015 | 123(71平) | -3.90pp | **25.3%** | 58 |
| **BBANDS 挤压** | **+27.1%** | **-1.4%** | **+0.066** | 139 | **+2.39pp** | 26.5% | 52 |
| RSI+挤压组合 | +26.2% | -5.7% | -0.037 | 140 | +1.54pp | 26.3% | 47 |

**结论**：
1. **BBANDS 挤压过滤是全部 7 个候选机制中唯一方向正确的**：收益均值 +2.4pp（唯一正均值改善）、中位收益 -1.4%（全配置最优）、夏普中位 0.066（最高）、配对胜率 52%、交易次数 -12%——"挤压=蓄势"语义在全池成立
2. **RSI 追高过滤温和有效**：中位收益与回撤改善，但均值 -3.9pp（过滤掉大牛股追高段的右尾收益），且 71 只完全持平（触发少）
3. **组合过滤负协同**（rsi+squeeze 中位 -5.7%）：双重抑制过度
4. 与 ADX/min_hold/exit 放宽不同，BBANDS 挤压**不依赖滞后确认**（当前状态），无"锁死"副作用——这是其有效性的结构性原因

**阈值敏感性（全池 288 只 × 4 配置）**：ratio=0.3 几乎不触发（196 只持平, 无效）；**ratio=0.5 最优**（均值 +2.4pp / 中位 -1.4% / 夏普 0.066）；ratio=0.7 过度抑制（交易降至 45, 均值 -5.0pp）。两侧变差的非单调性排除参数过拟合。

**HS300 实盘池组合回测**（stocks_hs300.yaml 配置, 500k 池/10 只/单只 10%, 300 只, 2020-2026, portfolio_backtest 模拟 daily_signal）：

| 指标 | 基线 | squeeze on | 变化 |
|---|---|---|---|
| 总收益率 | +121.5% | +129.5% | **+8.0pp** |
| 年化收益 | 19.3% | 20.5% | +1.2pp |
| 夏普 | **1.13** | 1.10 | -0.03 |
| 最大回撤 | **-18.7%** | -23.4% | **+4.7pp(变差)** |
| 总交易数 | 4502 | 4566 | +64 |

**组合层面最终结论**：squeeze 收益方向正确（+8pp），但**风险调整后不占优**——回撤扩大 4.7pp、夏普略降（组合层 max_positions 限制下过滤只改变候选标的, 交易数不变）。**建议保持默认关闭**，作为可选参数；若启用需接受回撤放大。综合 7 个候选机制 × 5 轮全池/组合验证：**BBANDS 挤压过滤是唯一收益方向一致的机制，但全池层面无系统性风险调整增益**——"震荡期防高频买卖"的结构性改进空间有限, 更根本的方向仍是退出机制（ATR 自适应宽度）。

### 12) ATR/NATR/SAR 自适应退出宽度（2026-08-04 全池+组合实证）

**实证前提**（21690 交易对按买入日 NATR 分桶）：快速反转亏损随波动单调加深——NATR<1.5% 时 -1.42%、>6% 时 **-4.73%**（快速反转比例 39%→53%）——高波动期 0.5% 固定退出阈值被洗出更频繁、亏损更深。

**实现**（signal_engine.py）：
- `atr_adaptive_exit_enabled`：退出阈值 = max(exit_threshold, exit_atr_factor × NATR)，高波动期放宽回归阈值
- `sar_exit_enabled`：Wilder SAR 跟踪止损（AF 0.02→0.2 递增，持仓期重置）

**单标的全池回测（288 只 × 5 配置，1440 次）**：

| 配置 | 收益均值 | 收益中位 | 夏普中位 | 优于基线 | 收益差中位 | 回撤中位 |
|---|---|---|---|---|---|---|
| 基线 | +24.7% | -4.8% | -0.017 | — | — | 27.4% |
| atr 0.5× | +27.9% | -3.3% | +0.048 | 132 | -0.58pp | 30.8% |
| **atr 1.0×** | **+33.2%** | **+1.95%** | **+0.106** | 149 | **+0.68pp** | 33.1% |
| SAR | +24.7% | -4.8% | -0.017 | 0（288 持平） | 0 | 27.4% |
| atr+SAR | 同 atr0.5 | — | — | — | — | — |

**HS300 实盘池组合回测（500k/10只/10%，300 只，2020-2026）**：

| 指标 | 基线 | atr 1.0× | 变化 |
|---|---|---|---|
| 总收益率 | +121.5% | **+135.6%** | **+14.1pp** |
| 年化收益 | 19.3% | **21.5%** | +2.2pp |
| 最大回撤 | -18.7% | **-18.1%** | -0.6pp |
| 总交易数 | 4502 | **2481** | **-45%** |
| 夏普 | 1.13 | 1.08 | -0.05 |

**结论**：
1. **NATR 自适应退出（1.0×）是全部 9 个候选机制中最强且首个全面正向的**：单标的全池收益均值 +8.5pp、**中位数转正（+1.95%）**、夏普中位 0.106、收益差中位 +0.68pp（首次全正）；组合层面收益 +14.1pp、**交易次数 -45%**（自适应退出直接砍半高频磨损）、回撤略改善
2. **SAR 完全无效**（288 只全持平）：0.5% 价格回归阈值总是先于 SAR 触发，SAR 被完全罩住——除非关闭价格回归信号，SAR 无独立价值
3. **代价**：单标的全池回撤中位数 +5.7pp（放宽退出后亏损交易持有更久）；组合层面不明显（持仓分散缓解）
4. **已落地（2026-08-04）**：`atr_adaptive_exit_enabled=true, exit_atr_factor=1.0` 已写入 `stocks.yaml` / `stocks_hs300.yaml` 默认启用（SAR 关闭）；回测 CLI `--atr-adaptive-exit`；默认配置组合回测确认生效（+135.6% / 2481 笔 / 回撤 -18.1%），测试 130 全绿

### 13) 量价确认象限研究：MFI 超买过滤（2026-08-05 全池+组合实证）

**实证前提**（21690 交易对按量价指标分桶）：
- **MFI(14) 区分度最强**：MFI<30 时快速反转仅 16.7%、往返 +1.31%、20 根收益 +2.36%；**MFI>70 时快速反转 71.6%**、往返 +0.75%——资金超买追高的信号质量最差（单调：16.7%→71.6%）
- OBV 方向同理（OBV↑ 买入快速反转 56% vs OBV↓ 34%）；量比/量能趋势区分度弱
- 与四象限文档"放量确认突破"直觉**相反**：放量追高才是坏信号

**实现**（signal_engine.py）：`compute_mfi`（与 talib 逐点一致）+ `mfi_filter_enabled / mfi_overbought / mfi_period`——MFI>70 抑制买入（资金超买追高过滤）。update 新增 volume 参数（strategy/daily_signal/portfolio_backtest 已接）。

**单标的全池回测（288 只 × 4 配置，1152 次）**：

| 配置 | 收益均值 | 收益差均值 | 收益差中位 | 优于基线 | 回撤中位 |
|---|---|---|---|---|---|
| 基线 | +24.7% | — | — | — | 27.4% |
| atr1.0（已落地） | +33.2% | +8.51pp | +0.68pp | 149 | 33.1% |
| MFI70 | +27.4% | +2.70pp | +0.72pp | **160** | **25.7%** |
| atr+MFI | **+46.5%** | **+21.82pp** | **+1.55pp** | 153 | 31.9% |

**HS300 实盘池组合回测**（基线含 atr 自适应退出 vs +MFI）：

| 指标 | 基线(含atr) | atr+MFI70 | 变化 |
|---|---|---|---|
| 总收益率 | +135.6% | +112.4% | **-23.2pp(变差)** |
| 夏普 | 1.08 | 0.96 | -0.12 |
| 最大回撤 | -18.1% | -19.7% | +1.6pp |

**结论**：
1. **MFI 超买过滤单标的层面有效**（回撤最低 25.7%、收益差中位 +0.72pp 为正），与 atr 组合后单标的全池均值 +21.8pp
2. **但组合实盘池层面明显有害**（-23.2pp）：组合 max_positions 限制下，被 MFI 过滤的信号会换成其他标的买入——而 MFI>70 恰是趋势最强阶段，过滤掉的是组合的右尾收益。单标的"跳过该标的"与组合"换标的"语义完全不同
3. **与 BBANDS 挤压过滤相同的模式**：单标的有效、组合层面负效果——**不纳入实盘默认配置**（保持 atr 自适应退出；MFI 保持可选参数默认关闭）
4. 量价确认象限结论：**"追高抑制"对单标的有效，但组合层面组合依赖追强票的右尾收益，过滤有害**——四象限研究至此全部完成（趋势/震荡/风控/量价确认），实盘落地仅 NATR 自适应退出一项

### 14) 转涨确认研究（2026-08-07 全池回测）

**背景**: 两态趋势(up/down)中"转涨"原本立即生效——close 在 MA20 ±1% 死区(实测占比 11%)内穿越时仓位跳变(30%→95%)敏感;但全池趋势切换频率极低(平均 0.4 次/90天/标的, 76% 标的本周期零切换)。

**实现**: `trend_recover_confirm_bars`——转涨需连续 M 天 close≥MA20 且 MA20 向上才切换, 确认期内保持 down(隐式中间状态, 无新增状态值)。

**全池回测(288只 × 4配置)**:

| 配置 | 收益均值 | 收益中位 | 夏普中位 | 优于基线 | 交易中位 |
|---|---|---|---|---|---|
| baseline(确认1=原行为) | +24.7% | -4.8% | -0.017 | — | 59 |
| rc2(确认2) | +16.6% | -1.9% | +0.059 | 131(45%) | 74 |
| rc3(确认3) | +19.0% | -3.4% | +0.032 | 110(38%) | 80 |
| rc3+ATR | +38.8% | +7.6% | +0.162 | 140(49%) | 74 |

**结论**:
1. **rc2/rc3 单独不建议启用**: 收益均值 -8pp——确认延迟让标的错过下跌转上涨的头几天(趋势收益最密集时段); 配对胜率 38-45%
2. **反直觉**: 交易次数反增(59→74-80)——确认延迟使标的状态停留 down 更久 → 更多下跌趋势 30% 小仓买入, 磨损不降反升
3. **rc3+ATR 中位 +7.6%**(全池迄今最高, 超过 atr1.0 单独的 +1.95%)——但主要为 ATR 贡献, 确认边际有限且配对胜率 48.6% 略降
4. **回撤**: rc3+ATR 中位 33.9%(+6.5pp)——ATR 放宽退出的系统性代价; 最大回撤个股 72%(连续止损复利: 30笔×-4%≈-71%)
5. **保留为可选参数**(默认 1 行为不变), 不纳入默认配置

### 与现有 kalman 策略的关联

`TrendDetector`（close vs MA20 + MA20 方向）目前只判断**多空方向**，不区分趋势/震荡——震荡期 MA20 方向会频繁翻转，导致信号抖动。若在 `signal_engine.py` 的 TrendDetector 里叠加一个 ADX≥20 的状态判定（趋势状态才允许方向翻转），即可把四象限的"趋势/震荡"识别接入现有系统。

### 分级过滤(2026-08-14)
**问题**: 基本面过滤全前置会误杀(28 只候选全部带"违规"标记——警示函/问询函/短线交易等轻重不一), 全后置则财务造假股占用推荐名额。**方案**: 三级分级——`red`(财务造假/重大行政处罚/立案/退市风险)前置剔除(数据下载/回测前, 省算力防污染), `yellow`(会计差错/1年内监管函/重大事项未披露)推荐时标注 ⚠️ 供人工判断, `light`(历史问询/个人行为)忽略。风险标记由妙想公司事件查询+人工分级为 `risk_flags.csv`, `screen_pool.py --risk-file` 合并过滤, 结果 CSV 增 `pre_filtered`/`risk_note` 审计列。

**实测**(57 只候选): 风华高科(2019 财务造假)前置剔除——其回测推荐第 4 名(+109.6%)本会污染推荐; 光智科技(2021 年报会计差错)推荐第一但标注 ⚠️ 黄线, 人工决定是否保留。推荐 9→8 只。测试 11 个, 全套 192 全绿。

### akshare 数据源替代妙想(2026-08-14)
**问题**: 妙想 MCP 是付费服务, 不可用/积分耗尽时选股流程中断。**方案**: 新增 `pool_provider.py`——候选池生成 akshare 免费源(默认): 指数成分(csindex 优先+新浪兜底) + 市值/成交额过滤 + ST 排除, 兼容妙想导出 CSV 合并, 输出列对齐 screen_pool。**实测**: akshare 756 只 ⊆ 妙想版 828 只(指数成分完全一致, 差异仅过滤条件)——双源可无缝切换。修复两个坑: 新浪代码 sh/sz 前缀清洗; csindex 列选择必须优先"成分券代码"(避免选到全是指数自身的"指数代码"列)。**唯一缺口**: 公司违规事件(风险分级)akshare 无接口, 妙想保留给低频风险核查。测试 6 个, 全套 198 全绿。
